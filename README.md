## Applications

- [LambChat](https://github.com/Yanyutin753/LambChat) - An open-source platform for building, running, and sharing AI agents.
- [Skills Manager](https://github.com/yibie/skills-manager) - A native macOS app for managing skills across coding agents.
- [OpenBiliClaw](https://github.com/whiteguo233/OpenBiliClaw) - A local-first AI agent that discovers personalized content across online platforms.
- [Rank Analysis](https://github.com/wnzzer/rank-analysis) - An AI-powered League of Legends companion for reviewing match performance.
- [OtakuWorld](https://github.com/jakepurple13/OtakuWorld) - A suite of apps for watching anime and reading manga and novels.
- [catgo-LRG](https://github.com/Hello-QM/catgo-LRG) - An AI-driven computational materials science workbench with 3D visualization and HPC workflow support.
- [Cashbook](https://github.com/WangJie0822/Cashbook) - A privacy-focused personal bookkeeping application.
- [opentypeless](https://github.com/tover0314-w/opentypeless) - An open-source AI voice-typing application for macOS, Windows, and Linux.
- [Polynoia](https://github.com/JuneQQQ/polynoia) - A local-first workspace for AI coding agents with durable identities and scoped memory.
- [auto-identity-remove](https://github.com/stephenlthorn/auto-identity-remove) - An automated data-broker opt-out application for macOS, Linux, and Windows.

## Plugins & Extensions

- [vscode-markdown-pdf](https://github.com/yzane/vscode-markdown-pdf) - A Visual Studio Code extension for exporting Markdown files to PDF and other formats.
- [GodotPrompter](https://github.com/jame581/GodotPrompter) - A plugin that provides Godot 4.x development skills to AI coding agents.
- [browser-ai-assistant](https://github.com/AhYi8/browser-ai-assistant) - A Chrome and Edge sidebar extension that provides an AI assistant using the current page context.

## CLI & Developer Tools

- [DashClaw](https://github.com/ucsandman/DashClaw) - A policy and approval layer that intercepts risky AI-agent actions before execution.
- [PyPhi](https://github.com/wmayner/pyphi) - A Python toolkit for research in Integrated Information Theory.
- [Fabro](https://github.com/fabro-sh/fabro) - A version-controlled workflow-graph tool for directing AI coding agents.
- [agent-spec](https://github.com/ZhangHanDong/agent-spec) - An AI-native BDD and specification-verification tool for coding-agent tasks.
- [Skill Flow](https://github.com/VintLin/skill-flow) - A tool for installing, managing, and sharing skills across coding agents.

## Integrations

- [teamspeak-music-bot](https://github.com/ZHANGTIANYAO1/teamspeak-music-bot) - A TeamSpeak music bot with a web interface and Chinese music-service support.

## Websites

- [Voting Info](https://github.com/bobmonsour/votinginfo) - Provides voter registration and voting requirements for all 50 US states plus Washington DC; [usvoting.info](https://usvoting.info/)
